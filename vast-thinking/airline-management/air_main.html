Project Overview & Origins

Built as an early independent programming project in high school to learn software logic, algorithmic workflows, and practical problem-solving. It is a fully text-based, menu-driven airline reservation and fleet operations manager running completely in Python.

Without relying on external third-party frameworks or databases, the program implements core operations including flight schedule viewing, seat availability decrements, ticket reservation, cancellation records, and formatted terminal boarding pass printouts.

Core System Features

Flight Schedule Browser

Displays available routes, departure/arrival timings, flight codes, and dynamic seat capacity tallies directly in the terminal.

Ticketing & Booking Logic

Takes user inputs, validates seat availability, assigns passenger records, and emits an organized booking confirmation.

File-Based Data Logging

Uses standard Python file I/O to read and append customer bookings, ensuring data isn't wiped between terminal runs.

Cancellation & Refunds

Searches saved records by passenger reference, updates status, and restores seat count back to the flight ledger.

What I Learned

  • Algorithmic Control Flow: Mastered loops, conditionals, and functional decomposition to build a reliable interactive menu loop without fatal crashes.
  • Data Handling Without Databases: Learned the foundations of file read/write modes, formatted strings, and parsing data records from flat files.
  • Engineering Foundation: Served as my initial hands-on dive into software design, which directly carried over into writing DAQ scripts and processing aerothermal data at Penn State.
