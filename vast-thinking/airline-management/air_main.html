Project Origins & Motivation

Built during 11th grade at Greenway Modern School, this project was developed collaboratively with my peer Aditya Saroha. Tasked with designing a functional system using early programming principles, we built an end-to-end airline operations manager purely within the terminal using core Python.

Collaborative Design & Early Engineering: Operating without external graphical frameworks or enterprise databases, we decomposed the platform into independent modules covering authentication, booking pipelines, cancellation ledgers, and flat-file data persistence. We split development across operational modules, debugged integration bottlenecks together, and co-presented the finished build.

Codebase Architecture & File Layout

Rather than writing a monolithic script, we organized the repository into modular subsystems mapped to operational airport workflows:

main.py / Begining file.py

System runtime entry points. Orchestrates introduction screens, manages the primary interactive command-loop, and delegates sub-menus.

login.py

Security and authentication gate. Verifies user credentials against local file records before granting operational access.

book.py

Reservation pipeline. Coordinates airport routing tables, checks passenger counts, decrements seat inventory, and records transactions.

cancellation.py

Ticket voiding mechanism. Locates existing passenger booking tokens, updates cancellation status, and releases seat allocation.

service.py

Generates customer boarding documentation, formats output summaries, and embeds interactive terminal utility modules (Game_1, IQchecker).

/data Storage Subsystem

Persistent flat-file database managing credential registries, airport networks (airports.txt), passenger rosters (pasng), and issued passes.

Foundational Engineering Takeaways

  • Early Collaborative Development: Gained initial experience in dividing software workflows between team members, aligning interfaces, and integrating multi-file systems.
  • Algorithmic Logic Without High-Level Abstractions: Tackled record persistence, input verification, and menu loops from first principles without depending on pre-built database drivers or web frameworks.
  • Pathway to Hardware & DAQ Systems: The logic and structured state-handling learned on this project became the direct precursor to scripting automated data acquisition pipelines and aerodynamic test-rig controls at Penn State.
