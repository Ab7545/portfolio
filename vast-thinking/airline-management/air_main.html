Project Origins & Motivation

Built during 11th grade at Greenway Modern School, this project was developed collaboratively with my peer Aditya Saroha. Tasked with designing a functional system using early programming principles, we built an end-to-end airline operations manager purely within the terminal using core Python.

Collaborative Design & Early Engineering: Operating without external graphical frameworks or enterprise databases, we decomposed the platform into independent modules covering authentication, booking pipelines, cancellation ledgers, and flat-file data persistence. We split development across operational modules, debugged integration bottlenecks together, and co-presented the finished build under the guidance of Mrs. Poonam Makhija.

Multi-Role Operational Flow

Engineered around three operational tiers mapped directly to airport and flight management workflows:

  • System Administrator: Manages airport routing tables (airports.txt), alters pricing/tariffs, and updates flight schedules.
  • Desk Officer: Handles counter ticketing, assigns seat reservations, searches flight availability, and updates booking manifests (pasng).
  • Passenger / Customer: Accesses account authentication, checks flight routes, cancels bookings, and generates verifiable boarding passes.

Codebase Architecture & File Structure

Entry & Orchestration (main.py)

Controls terminal startup, presents interactive menus, and coordinates module imports to prevent execution overlap.

Authentication Gate (login.py)

Validates incoming operator credentials against local data files before allowing access to operational commands.

Ticketing & Seat Ledger (book.py, cancellation.py)

Reads network routes from airports.txt, adjusts available seat tallies, and commits passenger transactions.

Flat-File Store (data/)

Maintains persistent customer manifests (pasng), generated boarding passes, and system logs without database overhead.

Foundational Engineering Takeaways

  • Early Collaborative Development: Gained initial experience in dividing software workflows between team members, aligning interfaces, and integrating multi-file systems.
  • Algorithmic Logic Without High-Level Abstractions: Tackled record persistence, input verification, and menu loops from first principles without depending on pre-built database drivers or web frameworks.
  • Pathway to Hardware & DAQ Systems: The logic and structured state-handling learned on this project became the direct precursor to scripting automated data acquisition pipelines and aerodynamic test-rig controls at Penn State.
